How to replace these

  1. Drop replacements into public/images/cars/ — keep the same base filenames (m2-hero.jpg and so on) and the swap needs no code change at all.
  2. Match the aspect ratio shown on each card. Everything is 1920px wide; heroes sit near 2.0 (wide cinematic crop), interiors and engines at 1.5.
  3. Every HERO file is used in four places — lineup card, expansion overlay, page hero, and first design detail. Pick one that survives a tight crop at all four.
  4. m4-hero.jpg additionally drives the intro reveal and homepage hero. In the homepage hero it renders object-fit: contain, so a transparent-background PNG cutout looks dramatically better there than a boxed photo.
  5. Keep files under roughly 500 KB. WebP at quality 82 will roughly halve the current weight at the same visual quality.
